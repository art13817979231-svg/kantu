# RefBoard PRD v2 — 设计师工作台

> 版本：2.0 · 路线：**B. 设计师工作台**  
> 定位：面向插画 / UI / 3D 创作者的**桌面参考图管理工具**，在 PureRef 的轻量画布之上，强化**组织、检索、对比、会话管理**能力。

---

## 1. 产品定位

### 1.1 一句话

**副屏常驻的参考图工作台**——不只是「把图铺在桌上」，而是能**分组、打标、检索、对比、导出**。

### 1.2 与 PureRef 的差异

| 维度 | PureRef | RefBoard 设计师工作台 |
|------|---------|----------------------|
| 核心 | 极简铺图 | 铺图 + 组织 |
| 结构 | 几乎无 UI | 可折叠侧栏 + 上下文面板 |
| 图量大时 | 靠肉眼找 | 图层列表 + 标签筛选 |
| 项目 | 单文件 | 项目 + 模板 + 自动保存 |
| 协作 | 无 | 导出评审图（PNG / 联系表） |

### 1.3 明确不做（v2 范围内）

- 矢量绘图、笔刷、路径编辑  
- 多人实时协作  
- 完整标注系统（Figma 级）  
- 云同步 / 账号体系（放到 v3 评估）

## 2. 用户画像与核心场景

### 2.1 用户画像

| 角色 | 诉求 |
|------|------|
| 插画师 | 角色 / 材质 / 配色参考分 group，对比前后稿 |
| UI 设计师 | 组件截图、状态稿并排，置顶对照画板 |
| 3D / 概念 | 大量 ref 图，按场景打 tag，快速显隐 |
| 美术指导 | 导出联系表给团队评审 |

### 2.2 核心场景（User Stories）

1. **情绪板搭建**：拖入 30+ 张图 → 自动网格排版 → 按「角色 / 场景」分组 → 保存 `.pur`  
2. **对照作画**：参考图置顶半透明 → 主画布在 PS/Procreate 作画  
3. **方案对比**：选中 2 张 → 左右对照模式 → 调透明度叠图  
4. **项目切换**：侧栏最近项目 → 打开客户 A / 客户 B 的 `.pur`  
5. **崩溃恢复**：自动保存临时文件 → 重启恢复未保存改动  
6. **评审导出**：导出当前视图为 PNG，或导出全部缩略图联系表

## 5. UI / UX 规范

### 5.1 设计原则

1. **画布优先**：UI 退后，默认紧凑；需要组织时才展开侧栏。  
2. **上下文就近**：选中图片时，属性在**底部浮层**操作，减少视线跳跃。  
3. **状态可见**：保存、锁定、隐藏、筛选，均有清晰图标，不靠猜。  
4. **渐进披露**：新手见空状态引导；高级功能在右键菜单和侧栏。

### 5.2 视觉 Token

### 5.4 画布视觉

- **默认背景**：深灰 + 低密度点阵（现有，保留）  
- **选中框**：`#4a9eff` 描边 + 8 锚点（现有）  
- **锁定图**：角标小锁图标，列表中灰色显示  
- **隐藏图**：画布不渲染，列表半透明  
- **分组框**：虚线包围盒（可选），折叠时不渲染子项包围盒

- 主文案 + 「导入图片」

## 6. 数据模型与 `.pur` v2 格式

### 6.1 运行时类型（扩展）

```ts
type ImageItem = {
  id: string;
  src: string;
  sourcePath?: string;
  name: string;           // 显示名，默认文件名
  x: number; y: number;
  width: number; height: number;
  scaleX: number; scaleY: number;
  rotation: number;
  opacity: number;
  zIndex: number;
  flipX: boolean;
  flipY: boolean;
  locked: boolean;
  visible: boolean;
  tags: string[];
  groupId: string | null;
  colorMark?: string;     // 可选色标 hex
};

type Group = {
  id: string;
  name: string;
  collapsed: boolean;
  childIds: string[];     // image ids
  x: number; y: number;   // 组锚点（可选）
};

type Viewport = { panX: number; panY: number; zoom: number };

type ProjectSettings = {
  alwaysOnTop: boolean;
  canvasBackground: "dots-dark" | "dots-light" | "checker" | "solid";
  canvasBackgroundColor?: string;
  sidebarCollapsed: boolean;
  compactMode: boolean;
};
```

### 6.2 manifest.json v2

```json
{
  "version": 2,
  "viewport": { "panX": 0, "panY": 0, "zoom": 1 },
  "settings": {
    "alwaysOnTop": false,
    "canvasBackground": "dots-dark",
    "sidebarCollapsed": false,
    "compactMode": false
  },
  "groups": [
    { "id": "g1", "name": "角色", "collapsed": false, "childIds": ["img1", "img2"] }
  ],
  "images": [
    {
      "id": "img1",
      "asset": "assets/img1.png",
      "name": "hero-ref.png",
      "x": 100, "y": 200,
      "width": 1920, "height": 1080,
      "scaleX": 1, "scaleY": 1,
      "rotation": 0,
      "opacity": 1,
      "zIndex": 1,
      "flipX": false,
      "flipY": false,
      "locked": false,
      "visible": true,
      "tags": ["角色", "正面"],
      "groupId": "g1",
      "colorMark": "#e85d5d"
    }
  ]

```

- **兼容**：`version: 1` 项目打开时自动迁移为 v2（补默认字段）。  
- **autosave**：`{projectName}.pur.autosave`，与正式文件同结构。

## 10. 风险与对策

| 风险 | 对策 |
|------|------|
| 功能膨胀变「小 Figma」 | 严格 P0 边界；标注只做箭头级或不做 |

| 分组嵌套 Konva 复杂 | v0.3 只做一层 group，不嵌套 |

## 12. 已确认决策（2026-05-22）

| # | 议题 | 决策 |

| 1 | 侧栏默认状态 | **默认折叠**，记住用户上次偏好 |
